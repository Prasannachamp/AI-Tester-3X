## 🆘 Troubleshooting

### Most Common Issues

**"JIRA API error: 401"**
- Go to: https://id.atlassian.com/manage-profile/security/api-tokens
- Create new token
- Copy and paste in app

**"Groq API error: 401"**
- Go to: https://console.groq.com/keys
- Create new key
- Copy and paste in app

**"No issues fetched"**
- Check JIRA project key
- Verify base URL is correct
- Ensure account has access

**"Strategy takes too long"**
- Normal! Groq needs 10-30 seconds
- Don't refresh page, just wait

### See Full Troubleshooting
→ Check **QUICK_REFERENCE.md**
